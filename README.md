# 카카오 노선 조회 웹앱

주소를 입력하거나 엑셀을 업로드하면 카카오 API로 주행거리, 예상시간, 톨비를 조회하는 Streamlit 웹앱입니다.

## 1. 설치

```bash
pip install -r requirements.txt
```

## 2. API 키 설정

`.env.example` 파일을 복사해서 `.env` 파일을 만들고 API 키를 입력하세요.

```bash
copy .env.example .env
```

`.env` 예시:

```text
KAKAO_LOCAL_REST_API_KEY=...
KAKAO_MOBILITY_REST_API_KEY=...
```

## 3. 실행

```bash
streamlit run app.py
```

실행 후 브라우저에서 안내되는 주소로 접속합니다.

## 4. 엑셀 업로드 양식

필수 컬럼:

- 출발지
- 도착지

선택 컬럼:

- 차종

차종 컬럼이 없으면 기본값은 `5톤`입니다.

## V8.4 변경사항
- 장소명 검색 결과 검증 시 카카오가 반환한 **지번주소를 우선 사용**합니다.
- 도로명주소에 읍·면·동이 생략되어도, 함께 반환된 지번주소가 원본 행정구역과 일치하면 채택합니다.
- 결과의 조회주소는 도로명주소를 우선 표시하고, 좌표메모에는 검증에 사용한 지번주소를 남깁니다.
